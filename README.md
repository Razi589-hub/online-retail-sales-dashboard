# 📊 Online Retail Sales Dashboard

## 📌 Project Overview

An interactive Power BI dashboard developed to analyze online retail sales performance and customer insights.

The dashboard provides an overview of revenue, orders, customers, quantity sold, average order value, monthly sales trends, country-wise revenue, and product performance.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## 📈 Dashboard Features

- Total Revenue KPI
- Total Orders KPI
- Total Customers KPI
- Quantity Sold KPI
- Average Order Value KPI
- Monthly Revenue Analysis
- Monthly Quantity Sold Analysis
- Country-wise Revenue Analysis
- Product-wise Revenue Analysis
- Interactive Year Filter
- Interactive Country Filter

## 🔄 Data Preparation

The dataset was cleaned and transformed using Power Query before building the dashboard.

Key preparation steps included:

- Data type correction
- Handling invalid records
- Cleaning transactional data
- Preparing date-related fields
- Creating analysis-ready columns

## 💡 Key Insights

- Revenue varies across months, with stronger sales activity toward the later months of the year.
- The United Kingdom contributes the largest share of revenue among the countries shown.
- A small group of products generates significantly higher revenue than other products.
- Quantity sold also increases toward the later months, indicating stronger sales activity during that period.

## 🎯 Project Objective

The objective of this project was to transform raw retail transaction data into an interactive business intelligence dashboard that helps users understand sales performance and identify important trends.

## 📷 Dashboard Preview

The dashboard provides an interactive view of sales performance through KPI cards, trend analysis, country analysis, and product analysis.
